# Personal Cloud Dashboard

Static HTML, CSS, and Vanilla JavaScript dashboard for the Personal Cloud backend.

## Files

- `index.html` - page structure and layout
- `styles.css` - dark responsive UI styling
- `script.js` - API integration and interactions

## What it shows

- Storage usage
- Free storage
- File count
- Server status
- Upload button

## How to use

1. Make sure the backend is running on `http://127.0.0.1:3000`.
2. Open `frontend/index.html` in a browser.
3. Use the Upload button to send files to the backend.
4. Use the Download and Delete buttons in the file list to manage uploads.
